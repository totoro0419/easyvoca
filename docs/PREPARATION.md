# EasyVoca｜準備確定事項（24チャット開始前）

## 目的と工程
- 対象：英語の基礎から大学入試の発展レベルまで広く。単語自体の易しさは「採用条件」ではない。
- 収録：一般的な意味だけでは気づきにくい別義・別品詞・語法のうち、現代英語・大学入試で学習価値があるもののみ。
- **24チャットの仕事は第1段階「候補抽出」と第2段階「根拠確認・採否確定」の両方**。
- コアイメージの詳細解説・例文・問題・アプリ実装は次工程。
- 全12,000語を独立した500語×24バッチで担当。採用語義数にはノルマを設けない。

## 固定マスターの設計
参照ファイル：`data/master/words.jsonl`（1行1見出し語）、`data/master/manifest.json`、`data/master/batches.json`。
単語番号はEasyVoca独自の固定索引。SVL公式順位やCEFR基準ではない。便宜上の1,000語ごとの帯はコーパス頻度を軸とした**近似順位**であり、教育段階・入試難易度の保証ではない。

利用したデータ：
1. LingevoがOANCから加工した米国英語の見出し語頻度リスト。再配布可、LingevoとOANCに表示上のクレジットが必要。
2. LexiCore-5000 v1.0.0、CC BY 4.0。**見出し語の照合補助だけ**に用い、品詞・CEFR推定値は直接信用しない。
3. 蛇・分・天気などの基礎語の取りこぼしを点検するための必須確認リスト（25語）。元データで確認できないものは人工的な頻度値を付けずに旗を立てる。

生成・検証方法：`scripts/build_master.py`、`scripts/validate_master.py`、`.github/workflows/build-master.yml`。
ファイル・出典・ハッシュはmanifestに記録し、生成後にマスターの内容が変更されても追跡できるようにする。

## 24チャット運用
共通プロンプトの**最後の独立した1行を1〜24の整数だけ**にする。冒頭・途中に番号を設定する必要はない。

- B=1：index 1〜500
- B=2：501〜1,000
- ...
- B=24：11,501〜12,000

各チャットは番号から `start=(B-1)*500+1` と `end=B*500` を計算し、固定マスターのその範囲だけを読む。見出し語を自主的に追加・置換・並べ替えない。複数チャットがマスターや共通仕様を書き換えない。担当専用の `selection/00001-00500` 等のブランチとPRに保存する。

## 第1段階で記録すること
- 対象500語の調査進捗（候補がない語も必ず記録）。
- 別品詞・知られていない意味・特殊構文などの候補。
- 日本語で短い語義、意外な理由、実用性。
- 出典の書誌情報またはURLと確認日。再配布不可の辞書本文は複製しない。

## 第2段階で記録すること
- 候補ごとの辞書・語法資料に基づく正確性の照合。
- `accepted`（採用）、`rejected`（不採用）、`needs_review`（要再確認）と理由。
- 採用したものは出典と使用上の条件を確認。AIの記憶だけで確定しない。
- 同じ意味の重複は統合し、意味が違うときは語義を分ける。

## 検証基準
1. 500番号が重複・欠落なく進捗管理されている。
2. 候補の単語・番号が必ずマスターと一致する。
3. 採用候補は品詞・意味・語法に根拠があり、出典が保存されている。
4. 候補ゼロの単語も調査済みであることがわかる。
5. 未調査・証拠不足・調査済み候補なしを混同しない。
6. 最終報告に対象範囲、調査語数、採用語義数、不採用語義数、要確認件数、PRとコミットを記載する。

## 品質上の注意
- 元のOANC資料は規模・ジャンルの偏りがあり、発音・語義・用法の保証ではない。
- レベル別の正確な教育適合性、活用形・同形異義語の分類は辞書調査で補う。
- 12,000語は「調査開始対象」を固定したものであり、「12,000語すべてに意外な意味がある」という意味ではない。
- 基本語や大学入試重要語の欠落が後から見つかっても、**並列調査中はマスターを書き換えない**。別リストに追加し次回の補完調査で扱う。
