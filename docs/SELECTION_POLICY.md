# 語義選定基準 v1

## 基本方針
調査対象は基礎語から大学入試レベルまでの幅広い単語。**単語自体が基本語であることは収録条件ではない。**
アプリで学習するのは、その単語で一般的に知られる意味・用法だけでは見落としやすく、学習価値が高い別義・別品詞・語法。

### 採用を検討する観点
1. **意味の意外性**：一般に知られる意味から予測しにくい。単なる言い換えは除く。
2. **品詞・構文・語法の盲点**：別品詞、構文による意味変化、特有の前置詞、意味・発音の変化。
3. **実用性**：現代英語の自然な用例があり、大学入試の読解や英作文等で知る価値がある。
4. **誤読リスク**：一般的な意味で解釈すると英文を読み間違えやすい。
5. **コアイメージとの関係**：明確な意味の連関があれば記録。無理に統一しない。

### 優先して調べる候補の例
- snake〔名〕ヘビ → snake〔動〕蛇行する
- minute〔名〕分 → minute〔形〕ごく小さい（発音も異なる）
- weather〔名〕天気 → weather〔動〕困難を乗り切る

例は基準の説明用。辞書・コーパス等で検証するまで採否・利用頻度を確定しない。

### 原則採用しない
- 基本義から自然に導けるだけの軽微なニュアンス違い
- 大学入試での価値が低い極めて稀な古語・方言・専門義
- 辞書・自然な用例で裏付けできない解釈
- 別語義に見えるが単なる定型的な日本語訳の違い

### 判断
- `accepted`：十分な根拠がある、意外で実用的な語義
- `candidate`：有用かもしれないが要確認
- `rejected`：学習対象には採用しない（短い理由を残す）
- `unverified`：根拠が足りない、または調査未完了

採用数のノルマを設定しない。採用ゼロの単語も正常。無理に意外な意味を作らない。

## 根拠と著作権
辞書の見出し、意味、用例の情報は情報源と確認日を記録する。出版社の辞書本文・例文を丸ごとコピーせず、許容されるデータを利用して、自分の言葉で短い日本語説明とオリジナル例文を作る。出典不明・検証不能なデータは採用確定にしない。

## 学習用データ（後工程）
採用した語義について、意味、品詞、コアイメージ（有効なときのみ）、自然なオリジナル例文、訳、必要な語法・発音上の注意を作る。今回の並列調査フェーズでは、候補発見と根拠収集を優先する。
