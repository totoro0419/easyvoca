# EasyVoca — 知っている単語の見落としがちな意味・語法を学ぶ

## 目的
基礎から大学入試レベルまでの英単語を広く調査し、一般に知られる意味からは気づきにくい別義・別品詞・語法を**厳選**する。辞書の全語義の暗記や複製が目的ではない。

## 24チャット並列作業（1〜24の番号で500語ずつ）
- 対象範囲の目標：12,000語を固定マスターとして準備。
- 第1段階：担当500語について収録候補を抽出する。
- **第2段階：各候補を辞書・語法資料で検証し、採用／除外／要確認を確定する。**
- この2段階を同じ担当チャットで続けて実行し、担当専用ブランチのPRに保存する。
- コアイメージ、完成例文、学習アプリの作成は**次の工程**。
- 完了の証拠は調査済み件数、採否結果、根拠、欠落・重複チェック。単語の採用件数にノルマを設けない。

## 必須の準備（未完了）
`data/master/words.jsonl` として、出典・公開利用条件を確認済みの**12,000語固定マスター**を作る。マスターを確定するまでは各担当は調査に着手しない。EasyVocaの通し番号は公式SVLの単語順位ではない。代替語彙リストを使う場合は出典と構成を明記する。
