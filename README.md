# EasyVoca — 見落としがちな英単語の意味・用法を学ぶ

## 目的
基礎から大学入試レベルまでの英単語を広く調査し、既知の意味からは気づきにくい別義・別品詞・語法を厳選して学習できるデータを作る。辞書の全語義を学習アプリに載せることは目的ではない。

## データ作成計画
- 調査範囲の目標：SVL12000相当の12,000語。基礎語の取りこぼしは別途補完する。
- 語義の選定：意外性、推測困難度、大学入試などでの実用性を総合判断する。
- 見出し語・品詞・語義を混同せず管理する。
- 500語×24バッチ。互いに独立したファイル・ブランチに成果物を保存する。
- **作業前に基準となる12,000語の固定マスターと出典・利用条件を確定する。現在は未確定。** 無い状態で範囲番号を推測して処理しない。

## 注意
このリポジトリは公開設定。著作権上の扱いが確認できない語彙リスト・辞書本文・用例文の大量転載を禁止する。
検証未完了のデータを「確認済み」としない。進捗は番号の処理件数で記録し、採用件数だけを進捗として扱わない。
